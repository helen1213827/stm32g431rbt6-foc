# FOC 术语表

> 这份表是为了让你能读懂代码。每个词给出：**一句话白话** → **代码里叫什么** → **怎么用**。
> 遇到看不懂的词先来这里查。

---

## 一、整体结构

### FOC（Field Oriented Control，磁场定向控制）
一句话：**把三相电流拆成"产生磁场的"和"产生力矩的"两部分，分别控制。**
就像开车时把方向盘和油门分开——三相电流本身是耦合的，拆开以后才好控制。

### 三级环（级联控制）
```
位置环(最外,慢)  →  速度环(中间)  →  电流环(最内,快)  →  SVPWM  →  电机
      ↑                  ↑                ↑
   编码器位置          编码器测速        电流采样
```
- **为什么从外到内越来越快**：内环要"来不及"的时候外环才能接管。内环慢，外环就只能更慢。
- 代码：`PositionLoop_Run()` / `SpeedLoop_Run()` / `CurrentLoop_Run()`，都在 `FOC_RunDrive()` 里依次调用。
- 频率：位置环 100Hz、速度环 1kHz、电流环 10kHz。见 `foc.c` 里的 `POS_DIV` / `SPD_DIV`。

### 带宽（bandwidth，ωc）
一句话：**这个环能跟多快的指令。** 带宽越高响应越快，但也越容易振。
- 代码里：电流环的带宽就是 `bw` 命令，单位 rad/s（400 rad/s ≈ 64Hz）。

## 二、坐标变换（电机控制的数学外壳）

### 三相 / αβ / dq
| 名字 | 是什么 | 好比 |
|---|---|---|
| **三相 (a,b,c)** | 真实的三个绕组电流 | 三维空间里的三个分量 |
| **αβ（静止坐标系）** | 把三相合成到平面上，不跟着转子转 | 用"东南西北"描述方向 |
| **dq（旋转坐标系）** | 跟着转子一起转，d 轴对转子磁场，q 轴垂直 | 用"车头方向 / 车右侧"描述 |

**为什么要转到 dq**：在 dq 里，力矩只跟 iq 有关、磁场只跟 id 有关，两个量解耦了。
在 abc 里，三个电流全都互相影响，没法单独调。

### Clarke / Park / 反 Park
| 函数 | 干什么 |
|---|---|
| `Clarke_Run()` | 三相 → αβ（静止） |
| `Park_Run()` | αβ → dq（旋转，需要角度） |
| `InvPark_Run()` | dq → αβ（从电压回到三相占空比） |

### θ（theta）/ 电角度 / 机械角度 / 极对数
- **机械角度**：转子实际转过的角度。
- **电角度** = 机械角度 × 极对数。这台电机 `POLE_PAIRS = 14`，所以转子转一圈 = 电角度转 14 圈。
- **为什么区分**：电机的力矩是随电角度周期变化的，控制必须用电角度。
- 代码：`mech`（机械弧度）→ `Angle_Update()` → `motor.theta`（电角度）。

### 电零点 / offset
一句话：**编码器的 0 度 ≠ 转子磁场的 0 度**，差的那个角就是 offset。
不校准它，电流就打在错误的轴上，电机推不动。→ 见"双探针校准"。

## 三、硬件相关

### SVPWM（空间矢量脉宽调制）
一句话：**根据想要的电压矢量，决定三个桥臂的开关时间**（占空比）。
代码：`SVPWM_Run()`，输出 `pwm.duty_a/b/c`。

### 占空比（duty）
一句话：开关管在一个周期里"开"的时间比例，0~100%。
- 代码里限制在 **5%~95%**，因为自举电容需要时间充电（`BSP_PWM_SetDuty()`）。

### 死区 / 死区补偿
- **死区**：上下两个开关管不能同时导通（会短路），所以切换时插入一小段都不导通的时间。
- **死区补偿**：这段死区会让实际电压比指令电压小一点，补偿就是把这个差值加回去。
- 代码：`g_dt_comp`，默认 0（关闭）。命令 `dtc`。

### 反电动势（back-EMF）
一句话：**电机转起来以后，它自己会"发电"，这个电压和外部加的电压对着干。**
- 转速越高反电动势越大。当它接近母线电压时，你就**再也加不进电流**了——环路失去控制权。
- 这就是"失控保护"存在的原因（故障码 2）。

### 母线电压（Vbus）
一句话：电源电压。12V。
- 代码里可用相电压上限 ≈ **6.2V**（`VBUS_LINEAR_MAX`），不是 12V，因为三相调制的原因。
- 你现在的电机相电阻 ~5~7Ω → **最大相电流 ≈ 1A**，这就是力矩的天花板。

### 磁链 ψf（flux）
一句话：永磁体的磁场强度。用它算反电动势前馈。
- 代码：`g_motor_flux`，当前是 0（=不做反电动势补偿）。

## 四、控制器（PID 那些事）

### Kp / Ki
- **Kp（比例）**：误差多大，就出多大力。**越大响应越快，越容易振。**
- **Ki（积分）**：误差一直存在就慢慢加力，专门用来**消掉稳态误差**。
- **重要**：代码里的 `Ki` 是"连续域增益"，公式是 `积分 += 误差 × Ki × dt`。
  所以**改控制频率必须重新算 Ki**，不能照搬。

### 饱和 / 限幅
一句话：**输出到了上限，再怎么加误差也出不来更多了。**
- 每个环都有自己的限幅：电流环限电压、速度环限电流、位置环限速度。
- 这一串限幅 = "闸门"，从内到外越来越宽。

### 抗饱和（anti-windup）
一句话：**已经饱和了就不要再积积分了**，否则松开时会把憋的劲一次性放出来。
- 代码：`pid.c` 的 `PI_Run()` 里的条件积分。

### 静差 / droop
一句话：**到位了但差一点点，停不在目标上。**
原因通常是摩擦力/齿槽力需要一点误差才能产生对应的力。用积分去补。

### 超调 / 振荡 / 极限环
- **超调**：冲过目标再退回来。
- **振荡**：一直在目标附近来回摆。
- **极限环**：因为某个地方饱和了，导致"冲过去→刹不住→冲回来"的固定周期摆动。**这是饱和问题，不是增益问题。**

### 相位裕度
一句话：**系统离振荡还有多远。** 45° 以上算安全。
延迟（滤波、采样）会吃掉相位裕度。

## 五、测量相关

### 测速滑窗
一句话：**用"N 毫秒前的位置"和"现在的位置"做差，除以时间。**
- 代码：`FOC_EstimateSpeed()`，窗口 = `FOC_TUNE_SPD_WIN_MS`（默认 10ms）。
- **窗口越短，噪声越大**：1 个编码器计数 ÷ 10ms 就相当于 0.96 rad/s 的速度。

### 量化噪声
一句话：**编码器最小只能分辨 1 个数，这个"最小台阶"折算成速度就是噪声。**
公式：`1 LSB 对应速度 = (2π/65536) / 窗口`。
- 这是速度环 `Kp` 上不去的根本原因：`Kp × 噪声 = 随机力矩`，看起来就是"电机在抖"。

### 低通滤波（LPF）
一句话：**只让慢的变化通过，快的（噪声）滤掉。**代价是引入延迟。
- 代码：`g_spd_lpf_ms`（命令 `spdf`，默认 15ms）。

### ISR（中断服务函数）
一句话：**定时器每 100µs 打断主程序一次，执行 FOC 计算。**
- 代码：`FOC_Run()`，由 TIM6 触发，10kHz。
- `t=23uS` 表示这一拍花了 23µs，预算 100µs。

## 六、这台机器特有的

### 双探针校准 / 探针（probe）
一句话：**给两个已知方向的电压，看电流实际往哪流，反推出坐标系的偏差。**
- `probe1`：vd=6V → 磁场指向 α 轴
- `probe2`：vq=6V → 磁场指向 β 轴
- 代码：`FOC_RunAlign()`，模式 1。

### 前馈（feedforward）
一句话：**提前把已知的扰动量加进去，不用等误差出现再反应。**
- 比如知道转速了，可以提前算出反电动势要多少电压，直接加上去。
- 代码：`g_ff_gain`（命令 `ff`），默认 0（关闭）。

### 参考轨迹 / S 曲线 / 加加速度（jerk）
- **参考轨迹**：不是直接把"目标位置"给位置环，而是先规划一条平滑的路径。
- **加加速度**：加速度的变化率。限住它，起步和停车就是 S 形而不是折线。
- 代码：`position_loop.c` 的 `POS_TRAJ_GAIN` / `POS_ACC_DEF` / `POS_JERK_DEF`。

### 失速 / 失控
| 故障 | 含义 | 故障码 |
|---|---|---|
| 失控 | 实际转速远超指令（反电动势顶到母线，失去控制） | 2 |
| 失速 | 速度模式下给了指令但电机不转 | 3 |
| KEY | KEY 引脚被拉低（按键或引脚悬空误触发） | 1 |
Qq
触发后会切到 DISABLED 并亮故障灯，**重新发一次 `mode` 命令恢复**。

## 七、串口命令速查

| 命令 | 作用 |
|---|---|
| `param` | **一次打印所有整定参数**（最常用） |
| `help` | 帮助 |
| `mode 0/1/3/4/5` | 关 / 校准 / 电流环 / 速度环 / 位置环 |
| `dbg 1~6` + `prd <ms>` | 换打印分组 / 改打印周期 |
| `spd <rad/s>` | 速度环目标 |
| `pos <counts>` / `posrel <counts>` | 位置环目标 / 相对移动 |
| `clkp clki bw` | 电流环 |
| `spdkp spdki iql spdf` | 速度环 |
| `poskp poski poskd posv posacc posjerk` | 位置环 + 轨迹 |
| `stall 0/1` | 失速保护开关 |
