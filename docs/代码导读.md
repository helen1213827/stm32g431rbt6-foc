## 五、最重要的三条"为什么"

### 1. 为什么三级环的频率必须 10:1 递减？
位置环 100Hz、速度环 1kHz、电流环 10kHz。
**内环必须比外环快至少 4~10 倍**，否则内环的延迟会被外环当成"积木"，
外环一加增益就振。代码里靠 `POS_DIV` / `SPD_DIV` 分频实现。

### 2. 为什么每个环都有自己的限幅？
```
位置环 → 限速度  ±v_max     (posv)
速度环 → 限电流  ±iql        (iql)     ← 真正的"力"在这限
电流环 → 限电压  ±6.2V                 ← 硬件天花板
```
限幅要放在**它该在的那一层**。链条上任一层缺失，整条链都要出问题。

### 3. 为什么 Kp 不能一直往上加？
$$\text{力矩噪声} = K_p \times \text{测速噪声}$$
测速噪声来自编码器量化（见术语表"量化噪声"）。Kp 太大时，
环路在拿噪声当力矩指令 → 电机抖动。**这是测量问题，不是调参问题。**

## 六、改代码的规矩

| 想改什么 | 改哪 |
|---|---|
| 改参数默认值 | `FOC/Inc/foc_tune.h` |
| 加串口命令 | `BSP/Src/bsp_cmd.c`（命令表 + help），落到 `foc_params.c` |
| 改控制算法 | `foc.c` 的 `FOC_RunDrive` 或对应的 `*_loop.c` |
| 加调试打印 | `BSP/Src/bsp_cmd.c` 的 `BSP_CMD_PrintDebug` |

⚠️ **`Core/`、`Drivers/` 下的文件是 CubeMX 生成的，不要手改** ——
重新生成时会覆盖。新代码写在 `/* USER CODE BEGIN */` 区域内。

## 七、最常见的调试入口

```c
param                    // 一眼看全部参数
dbg 3  + prd 50          // 看速度环: spd 追不追得上 rr
dbg 4  + prd 50          // 看位置环: spd 追不追得上 pspd
dbg 2  + prd 50          // 看测速噪声: spdw 的跨度
dbg 1                    // 看电流环: idw/iqw 的跨度(振荡指标)
isr                      // ISR 耗时 last/avg/max
```
